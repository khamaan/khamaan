## Featured Agentic AI Projects
[DevRelay Crew](https://github.com/khamaan/devrelay-crew) — a CrewAI and Gemini-powered local web app built with Codex. An engineering manager delegates research, coding, and review to specialist agents, shows their tool activity, and returns Python code and tests for human review.

[LeadFlow Agent](https://github.com/khamaan/leadflow-agent) — a local browser app built from scratch with Codex and powered by Gemini API function calling. It shows read-only catalog and case-study tool steps live, then prepares a CRM lead recommendation and follow-up draft for human review.
